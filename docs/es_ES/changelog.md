# Changelog Alexa Devices

## [0.9.0] - 14/11/2026
### Añadido
- Versión inicial estable para Jeedom v4 / v4.4+.
- Soporte para flujo push HTTP/2 en tiempo real con Amazon AVS.
- Descubrimiento automático de altavoces Echo y dispositivos Alexa.
- Text-to-Speech (`speak`) y anuncios sonoros (`announcement`).
- Emulación de comandos de voz por texto (`text_command`).
- Control deslizante interactivo de volumen (0-100) bidireccional.
- Controles de reproductor multimedia (Play, Pause, Next, Previous).
- Control del modo No Molestar (DND).
- Historial de última orden vocal transcrita (`last_command`).
- Asistente de conexión con verificación en dos pasos (2FA OTP).
- Widgets personalizados para Dashboard y versión móvil.
- Soporte multilingüe completo (español, inglés, francés).
