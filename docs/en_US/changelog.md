# Changelog Alexa Devices

## [0.9.0] - 2026-11-14
### Added
- Initial stable release for Jeedom v4 / v4.4+.
- Real-time Amazon AVS HTTP/2 push stream support.
- Automatic Echo and Alexa device discovery.
- Text-to-Speech (`speak`) and Announcements (`announcement`) with attention chime.
- Emulated voice command via text (`text_command`).
- Interactive volume slider (0-100) with bidirectional synchronization.
- Media player controls (Play, Pause, Next, Previous) and state display.
- Do Not Disturb (DND) mode control.
- Voice transcription history display (`last_command`).
- Interactive Two-Factor Authentication (2FA OTP) wizard.
- Dedicated custom dashboard and mobile widgets.
- Full multilingual support (English, French, Spanish).
